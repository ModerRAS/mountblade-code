# 变量名美化方案

## 🎯 美化目标

将Ghidra逆向生成的变量名替换为具有语义的名称，提高代码可读性和可维护性。

## 📊 美化统计

| 变量类型 | 数量 | 主要分布文件 | 美化难度 |
|---------|------|-------------|----------|
| DAT_ | 80,662个 | 02_core_engine.c, 03_rendering.c | 高 |
| local_ | 11,074个 | 03_rendering.c, 04_ui_system.c | 中 |
| s_ | 8,873个 | 03_rendering.c, 04_ui_system.c | 中 |
| UNK_ | 7,467个 | 03_rendering.c | 高 |
| FUN_ | 349个 | 99_unmatched_functions.c | 中 |
| LABEL_ | 330个 | 99_unmatched_functions.c | 低 |

## 🔧 美化策略

### 1. DAT_ 变量美化策略

**美化原则：**
- 根据变量用途和上下文推断功能
- 使用PascalCase命名规范
- 保持数据类型和内存布局不变

**具体策略：**

#### 1.1 UI系统DAT_变量美化
```c
// 美化前
#define UILookupTableF70 DAT_180956f70
#define UIComponentDataTableB8 DAT_1809536b8
#define UIContextDataTableB0 DAT_1809542b0

// 美化后
#define UILookupTableF70 UILookupTableData
#define UIComponentDataTableB8 UIComponentDataTable
#define UIContextDataTableB0 UIContextDataTable
```

#### 1.2 渲染系统DAT_变量美化
```c
// 美化前
#define DAT_180d49678 RenderSystemCallbackData
#define DAT_180a09de8 RenderMaterialPropertyNode
#define DAT_180d48e24 RenderSystemInitializationData

// 美化后
#define RenderSystemCallbackData RenderSystemCallbackData
#define RenderMaterialPropertyNode RenderMaterialPropertyNode
#define RenderSystemInitializationData RenderSystemInitializationData
```

#### 1.3 核心引擎DAT_变量美化
```c
// 美化前
// 系统状态缓冲区常量 - 用于替换UNK_180a081b4等变量

// 美化后
#define SystemStateBufferUnk_180a081b4 SystemStateBuffer
```

### 2. local_ 变量美化策略

**美化原则：**
- 根据函数作用推断变量用途
- 使用描述性的命名
- 保持变量作用域不变

**具体策略：**

#### 2.1 渲染系统local_变量美化
```c
// 美化前
#define local_10 LocalMaterialVariable10
#define local_20 RenderMaterialPropertyOffset20
#define local_30 RenderMaterialPropertyOffset30

// 美化后
#define LocalMaterialVariable10 MaterialPropertyVariable10
#define RenderMaterialPropertyOffset20 MaterialPropertyOffset20
#define RenderMaterialPropertyOffset30 MaterialPropertyOffset30
```

#### 2.2 未匹配函数local_变量美化
```c
// 美化前
#define LocalVariable10 local_10
#define LocalVariable11 local_11
#define LocalVariable12 local_12

// 美化后
#define LocalVariable10 SystemLocalVariable10
#define LocalVariable11 SystemLocalVariable11
#define LocalVariable12 SystemLocalVariable12
```

### 3. UNK_ 变量美化策略

**美化原则：**
- 基于使用上下文推断功能
- 使用中性命名避免误判
- 添加注释说明推断依据

**具体策略：**

#### 3.1 UI系统UNK_变量美化
```c
// 美化前
#define UIComponentParameterB20 UNK_180958b20
#define UIComponentDataF50 UNK_180956f50
#define UIComponentHandleF38 UNK_180956f38

// 美化后
#define UIComponentParameterB20 UIComponentParameterData
#define UIComponentDataF50 UIComponentDataBuffer
#define UIComponentHandleF38 UIComponentHandleData
```

#### 3.2 渲染系统UNK_变量美化
```c
// 美化前
#define UNK_18098e3b0 RenderMaterialTextureDefault
#define UNK_180a16f78 RenderMaterialConflictData
#define UNK_180958b00 UIComponentInterfaceID

// 美化后
#define RenderMaterialTextureDefault RenderMaterialTextureDefault
#define RenderMaterialConflictData RenderMaterialConflictData
#define UIComponentInterfaceID UIComponentInterfaceID
```

### 4. FUN_ 函数美化策略

**美化原则：**
- 根据函数功能推断用途
- 使用动词+名词的命名模式
- 保持函数签名不变

**具体策略：**

#### 4.1 工具函数美化
```c
// 美化前
#define ExecuteSystemCheckA0 FUN_180899dc7
#define ProcessAdvancedDataOperationA0 FUN_18089a370
#define ExecuteDataCleanupA0 FUN_18089a51d

// 美化后
#define ExecuteSystemCheckA0 ExecuteSystemCheck
#define ProcessAdvancedDataOperationA0 ProcessAdvancedDataOperation
#define ExecuteDataCleanupA0 ExecuteDataCleanup
```

#### 4.2 系统函数美化
```c
// 美化前
undefined ManageSystemDeviceDrivers_1803c56d0;
undefined ProcessSystemMemoryOperations_1803c5710;
undefined SystemRenderPass_180a25390;

// 美化后
void ManageSystemDeviceDrivers(void);
void ProcessSystemMemoryOperations(void);
void SystemRenderPass(void);
```

## 🛠️ 实现工具

### 1. 批量替换脚本
```bash
#!/bin/bash
# 批量替换DAT_变量
sed -i 's/DAT_[0-9a-fA-F]*/SemanticName/g' file.c
```
